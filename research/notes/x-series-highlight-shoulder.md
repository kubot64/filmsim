# ハイライトの肩の補正の当てはめと交差検証

公式 LUT の出力をカメラの撮って出し JPEG と比べると、参照の L* 80 以上が、ハイライトのある 14 組すべてで暗かった（L* −2〜−15）。Provia 7 組（X100VI ×4、X-T5 ×3）で −2.4〜−8.6、Classic Chrome 7 組（X-Pro2 ×4、X-T50、X-Pro3、GFX 50S II）で −1.9〜−15。LUT の後ろにカーブ全体の補正を入れる案は別の機種に効かなかったが（#10）、ずれの向きがどの機種でも揃っているのはハイライトだけなので、肩だけの補正を試した（#16）。採用した判断は [ADR 0004](../../docs/adr/0004-x-series-corrections-only-on-fujifilm-luts.md)。

## 補正の形

- LUT の出力の輝度 y に `y' = y·(1−w) + y^γ·w`（`w = smoothstep(knee, 1, y)`）を掛ける
- 掛け方は輝度の比（RGB の比率を保つ）。RGB の各チャンネルに掛ける方法も試したが、輝度の比の方が同じか少し良かった
- 露出は DR100 で +1.125 EV、DR200 で +2.125 EV に固定。800px に縮小して比較した
- 評価は、組ごとに 3 つの ΔE 中央値（参照 L* 80 以上の帯、L* 60〜80 の帯、全体）の平均。ハイライト帯だけで評価すると、膝を 0.5 まで下げた強い補正が選ばれ、中間調を壊した

## 交差検証（抜いた側、補正なし → あり）

| 抜いた機種 | 選ばれた設定 | ハイライト帯 | L* 60〜80 | 全体 |
|---|---|---|---|---|
| X100VI（Provia ×4） | 膝 0.6 / γ 0.5 | 4.03 → 2.26 | 3.02 → 2.74 | 2.60 → 2.31 |
| X-T5（Provia ×3） | 膝 0.6 / γ 0.4 | 2.61 → 1.73 | 1.53 → 1.59 | 2.48 → 2.53 |
| X-H1（CC） | 膝 0.6 / γ 0.5 | 6.13 → 3.79 | 1.30 → 0.96 | 1.43 → 1.26 |
| X-Pro2（CC ×4） | 膝 0.6 / γ 0.5 | 4.91 → 3.06 | 3.44 → 3.46 | 4.06 → 3.96 |
| X-Pro3（CC） | 膝 0.6 / γ 0.5 | 5.27 → 3.42 | 5.39 → 5.42 | 2.13 → 2.10 |
| X-T50（CC） | 膝 0.6 / γ 0.5 | 6.26 → 4.45 | 5.79 → 6.24 | 4.04 → 3.84 |
| GFX 50S II（CC） | 膝 0.6 / γ 0.4 | 1.61 → 2.01 | 1.11 → 2.82 | 2.88 → 3.57 |
| Provia → CC | 膝 0.6 / γ 0.5 | 4.86 → 3.17 | 3.42 → 3.62 | 3.34 → 3.29 |
| CC → Provia | 膝 0.6 / γ 0.4 | 3.42 → 1.96 | 2.38 → 2.24 | 2.55 → 2.38 |

ハイライト帯は、7 機種中 6 機種と、Provia と Classic Chrome の両方向で改善した。例外は GFX 50S II だけで、全部の指標が悪化した。この組はもともとハイライトのずれが最も小さく（L* −1.9）、公式 LUT は GFX 用なので、ハイライトの差は X シリーズの JPEG エンジンと GFX 用 LUT の差である可能性がある。ただし GFX は 1 組だけで、DR200 を X RAW Studio で現像したものなので、結論は出せない（#73）。

## 全 15 組で当てはめた場合

膝 0.6 / γ 0.5 で、ハイライト帯 4.19 → 2.59、L* 60〜80 は 2.93 → 2.95、全体 2.97 → 2.87。全体の ΔE が悪化したのは 15 組中 2 組（X-T5 の 1 組 +0.10、GFX +0.42）で、ハイライト帯が悪化した組はない。
