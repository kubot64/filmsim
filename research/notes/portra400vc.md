# Portra 400VC の LUT の作り方

Portra 400VC はネガフィルムなので、RAW と撮って出し JPEG のペアがない。Kodak の技術資料から特性曲線と分光データを読み取り、ネガとプリントを計算で通して LUT に焼いた（#38、[ADR 0006](../../docs/adr/0006-non-fujifilm-looks-as-flog2-luts.md)）。入出力は公式 LUT と同じ（F-Log2 → sRGB のコード値）。

- データ：`research/filmsim/portra400vc.py`
- 計算：`research/filmsim/negative.py`、`scripts/bake_negative.py`
- 出力：`ios/FilmSim/LUTs/Portra400VC_65grid.cube`（公式 LUT と違い git で管理する）

## 技術資料から読み取ったもの

Kodak の技術資料（TSC 0597-2 日本語版、2006。Portra 160NC / 160VC / 400NC / 400VC / 800 をまとめた 1 冊）の 400VC のページから、ベクター図の線をそのまま数値にした。

- 特性曲線（Status M、C-41）。直線部のガンマは R 0.58、G 0.58、B 0.67。基準露光（中間グレー）は log H = −1.44
- 中間グレーと D-min の分光濃度
- 3 層の分光感度

## 計算の手順

1. **線形 BT.2020 → 3 層の露光量**：分光感度から 3x3 行列を作る。ColorChecker 24 色の分光反射率 × D65 で、RGB と各層の露光量を最小二乗で結ぶ。昼光用フィルムなので、グレーは 3 層で等しくなるよう行をそろえる
2. **露光量 → トーン**：3 本の特性曲線をそれぞれのガンマで割って平均した 1 本を、3 チャンネルに共通で掛ける。足で影が詰まり、肩でハイライトが残る形はここから来る。チャンネルごとに別の曲線を掛けると、足の始まりがずれていてグレーに色が付いた（ColorChecker の黒が紫になった）。スキャナーのチャンネルごとのレベル合わせに当たる
3. **プリント**：輝度と、各チャンネルの輝度からのずれに分けて扱う（log 単位）。ずれに彩度を掛け、輝度に S 字の曲線を掛ける。影は、フィルムのベース（D-min）が中間グレーから決めた段数だけ下で黒になるよう、輝度だけを引き延ばす
4. **スキャン**：表示の線形 RGB にスキャナーの 3x3 の色行列を掛ける。各行の和は 1 なので、グレーはグレーのまま

## スキャンへの当てはめ

3 と 4 の値は資料にないので、ColorChecker が写った Portra 400VC の実際のスキャン（Flickr の tgray1 さんのアルバム「Portra 400VC test」、`research/filmsim/portra400vc_scan.py` に 24 色の測定値）に当てはめた。スキャンの明るさとグレーのバランスは自由にして、24 色の ΔE2000 の平均を最小にした。

- 結果は平均 3.3、中央値 2.8（何もしない本来の色だとスキャンと 17 違う）
- 値はコントラスト 1.83、彩度 1.15、影 9.7 段、黒 0。色行列は R 行が (1.267, −0.317, 0.050)
- 赤がスキャンどおり 36° のオレンジ寄りになるのは、この色行列による（行列なしでは 18°）
- ユーザーの作例 5 枚（深い青空と赤い風船、黄緑の椅子とバイオリン、ポートレート 2 枚、赤いギンガムチェック）でも、赤はオレンジ寄り（25〜38°）、青はシアン寄りだった

## 気づいたこと

- スキャンは 18% の中間グレーより約 1.2 段明るく置かれていた。アプリの LUT はほかのルックと同じ 18% の置き方で焼いたので、スキャンのような明るく軽い見た目にするなら、撮影時の露出補正を上げる
- 同じアルバムの −4〜+5 段のブラケットは、スキャナーがコマごとに明るさをそろえていて、トーンカーブは測れない。+5 段でも破綻せず、−3 段から黒が浮いて白が落ちる（足が尽きる）のは、モデルの形と合う
- 格子は 65（公式 LUT と同じ）。33 では三線形補間で中間グレーが 0.166 / 0.172 / 0.171 になり、わずかにシアンに寄った

実機で撮って彩度とコントラストを詰めるのは #77。
