# CIRAWFilter の EDR を 1 にして、線形の 1.0 より上を残す

CIRAWFilter の `extendedDynamicRangeAmount` を 1 にする（#24）。0 だと線形の 1.0 で切られ、光源のまわりに残っている赤と青のデータ（最大で約 1.3 段）を捨てる。線形 1.0 は Provia を通しても sRGB 223 にしかならないので、照明や自動販売機の画面が、くすんだ明るいグレーで止まっていた。1 にすると光源は 241〜246 まで白くなり、明るい面の細部も戻る。中間調は変わらない。

線形 1.0 付近を式で引き伸ばす案は、細部が戻らず、飽和の手前のノイズを増やしたので採らなかった。

## Consequences

- センサーが完全に飽和した部分は CIRAWFilter が推定で埋める（EDR に比例して最大値が増えるので推定とわかる）。晴れた屋外でこれが自然に見えるかは未確認（#68）
