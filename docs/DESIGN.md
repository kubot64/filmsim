# 設計判断（2026-09-25 時点）

議論して合意した内容。変更するときはこのファイルを更新する。

## 目的と対象

| 項目 | 決定 | 理由 |
|---|---|---|
| 目的 | まず自分用 | 商標や課金を気にせず色の再現精度に集中する |
| 狙う見た目 | X100 系のフィルムシミュレーション | 公式 LUT が基準に使え、参考作例が多い |
| 実機 | 持っていない | RAW/JPEG ペアを自分で撮れないので公式 LUT と公開データで代替 |
| 端末 | iPhone 15/16/17 世代（48MP メインカメラ） | センサークロップ後も解像度が残る |

## 色の基準

- 富士フイルム公式の F-Log2 → フィルムシミュレーション LUT（.cube、65 grid）を「正解」とする
  - Provia / Classic Chrome を含む 10 種は GFX ETERNA 55 用パッケージに入っている。X100VI 用パッケージは ETERNA 系だけ
  - 取得は `scripts/fetch_luts.sh`（URL と SHA-256 を固定）。リポジトリにはコミットしない
- 入力側は F-Log2 データシート Ver.1.1 の式で線形 → F-Log2 に符号化する
  - `a=5.555556 b=0.064829 c=0.245281 d=0.384316 e=8.799461 f=0.092864 cut1=0.000889 cut2=0.100686685370811`
  - 18% 反射 → 0.391（IRE 38、10bit 400）、90% → 0.557（570）
- F-Gamut の原色は BT.2020 と同一、白は D65

## パイプライン

```
Bayer RAW (DNG)
  → CIRAWFilter（boost 0、ローカルトーンマップ 0、Apple のノイズ除去とレンズ補正は使う）
  → 線形 P3(D65)
  → 35mm / 3:2 クロップ（捨てる周辺はここから先に流さない）
  → WB シフト（R/B の係数を線形空間で掛ける）
  → 露出アンカー（線形の 18% を F-Log2 の 0.391 に合わせる。要調整。OPEN_QUESTIONS 参照）
  → P3 → F-Gamut(BT.2020) 行列変換
  → F-Log2 符号化
  → 公式 3D LUT（Provia / Classic Chrome）
  → ハイライト/シャドウトーン
  → グレイン
  → HEIC 書き出し（BT.709 としてタグ付け。コード値は変換しない）
```

LUT は F-Log2 のコード値をそのまま引く。出力は BT.709 ガンマなので、HEIC には追加の色変換をしない。P3 へ広げる変換はしない。

トーンとグレインの重み・振幅・σ は `research/filmsim/tone.py` と `grain.py` を正とし、Swift / Metal はそれに合わせる。グレインの乱数分布は一致しない。Python は正規乱数で、iOS は `CIRandomGenerator` の一様乱数をぼかして標準偏差だけ `grain.unit_noise_gain` に合わせている。σ=0.6 では分布の形が違う。色行列は線形 RGB に WB と露出を掛けてから P3 → F-Gamut する（`out = M · (rgb × gains)`）。プレビューのグレイン粒径だけ解像度に比例させる。

## スコープ

- 初期のフィルムシミュレーションは Provia と Classic Chrome の 2 種
- LUT 以外の調整項目は グレイン、H/S トーン、WB シフト の 3 つ。カラークローム効果と明瞭度は後回し
- 撮影中のプレビューは色を掛けない。フレーミングは保存時と同じ 35mm / 3:2 にする
- 保存は HEIC を常に、DNG は設定で切替（初期はオン）
- メインカメラを 35mm 相当にセンサークロップ、3:2 固定

## 検証

- DPReview 等の公開サンプルの RAF と撮って出し JPEG のペアを使う
- RAF を LibRaw で線形 BT.2020 に現像 → F-Log2 → 公式 LUT → JPEG と ΔE2000 で比較
- Python（`research/`）で先に組んで確定させ、確定した式と中間画像を Swift 側のテスト期待値にする

## やらないこと

- 古い FinePix の CCD コンデジ風の質感（低解像度、白飛び、日付スタンプ）
- 自前のデモザイク・ノイズ除去
- ライブプレビューへの LUT 適用（MVP では）
- App Store 配布のための商標回避や課金
