# 入力は 12MP の Bayer RAW にする

iPhone のメインカメラは 48MP だが、Bayer RAW は 48MP を指定しても 12MP（4032×3024）で返る（iPhone 15 Pro Max で確認、#5）。48MP の RAW は ProRAW しかない。入力は 12MP の Bayer RAW にする。

12MP の Bayer RAW には Apple の処理（デモザイク後の局所トーンマップ、多フレーム合成）が入っていない。そのため、色のずれを自分のパイプラインの中で切り分けられ、公開 RAF での検証と同じ前提で進められる。ProRAW はデモザイクとノイズ除去が済んだリニア DNG で、Apple の局所トーンマップが情報として入っているので、露出アンカーと色の処理を ProRAW 用に決め直す必要がある。

## Consequences

- 3:2 で 35mm 相当に切り出すと約 2765×1843（約 5MP）になる。24mm は 4032×2688、28mm は 3456×2304。50mm は約 2.5MP になるので入れない
- iPhone 16 / 17 世代もメインカメラは同じ 48MP のクアッドピクセルなので同じと見込むが、実機では確かめていない
- 見た目が仕上がった段階で、同じ場面を 48MP ProRAW でも撮って比べ、切り替えを考える（#70）
