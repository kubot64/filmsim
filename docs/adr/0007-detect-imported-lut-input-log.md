# 読み込む LUT の入力 Log はファイルから判定し、S-Log3 用は F-Log2 用に焼き直す

使う人は .cube を読み込んでルックに足せる。.cube には入力の Log を書く決まった欄がないので、何用の LUT かは使う人に選ばせず、ファイル名と TITLE、コメント行に書かれた「F-Log2」「S-Log3」「S-Gamut3.Cine」などから判定する。実際のファイルは、たいてい名前に書いてある（富士の `FLog2_to_…`、Sony の `SLog3SGamut3.CineTo…`）。

判定できないもの（何も書いていない、S-Log3 で色域が書いていない、F-Log2 と S-Log3 の両方が書いてある）と、未対応のもの（F-Log2 C、初代 F-Log、V-Log、C-Log など）は読み込まない。違う Log として読むと、エラーにならないまま色がおかしくなるため。

S-Log3 用に対応するのは、フィルム風の LUT が F-Log2 用より S-Log3 用のほうがずっと多いため。読み込むときに「F-Log2 のコード値 → 線形 → S-Gamut3(.Cine) → S-Log3 のコード値 → その LUT」を 65 grid の F-Log2 用 LUT に焼き直して保存するので、撮影時のパイプラインは変わらない（[0006](0006-non-fujifilm-looks-as-flog2-luts.md)）。

## Consequences

- 読み込むファイルはどこから来たものでもよいので、変な・悪意のあるファイルでもアプリを落とさず、理由を出して断る
- ほかのメーカーの公式 LUT はたいてい Log を標準の見た目に直す変換用で、読めてもそのメーカーの写真モードにはならない
