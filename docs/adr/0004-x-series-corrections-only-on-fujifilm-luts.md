# X シリーズの撮って出しに寄せる固定の補正を、富士の LUT にだけ掛ける

公式 LUT は GFX 用で（[0001](0001-official-flog2-lut-as-colour-reference.md)）、狙う見た目は X シリーズの撮って出しなので、LUT の後ろに 2 つの固定の補正を入れる。どちらも富士のフィルムシミュレーションにだけ掛け、ほかのルック（焼いた LUT、当てはめた LUT、読み込んだ富士以外の LUT）には掛けない。

- **ハイライトの肩**（#16）：LUT の出力は、参照 L* 80 以上が 7 機種 15 組のどれでも撮って出しより暗い。輝度 0.6 から上を γ 0.5 の方向へ smoothstep で寄せ、RGB は輝度の比で掛ける（色相は変わらない）
- **Provia の暖色の色相**（#11、#32）：赤が +5°、橙が +7〜8° 黄色寄りになる。Cb/Cr の角度だけを、中心 140° で −7° 回す

どちらも 1 機種を抜く交差検証で、抜いた機種でも改善したので採用した。ただし GFX 50S II では肩の補正で悪化した。したがってこれは LUT を正す補正ではなく、X シリーズの見た目に寄せる補正として扱う。ペアから当てはめた LUT には、そのカメラのハイライトが最初から入っている。

測定の詳細は [x-series-highlight-shoulder.md](../../research/notes/x-series-highlight-shoulder.md) と [provia-warm-hue.md](../../research/notes/provia-warm-hue.md)。

## Considered Options

- **LUT の後ろにカーブ全体の補正を入れる**（#10）：別の機種に効かなかった
- **Classic Chrome にも暖色の回転を掛ける**：ずれが小さく（+1〜+6°）、Provia の回転を掛けると 7 組中 2〜3 組で全体の ΔE が悪化した

## Consequences

- 読み込んだ LUT でも、ファイル名が `FLog2_to_` で始まるもの（富士の公式の名前）には同じ補正を掛ける
- GFX の見た目に合わせたくなったら、機種ごとに切り替えるかを見直す（#73）
