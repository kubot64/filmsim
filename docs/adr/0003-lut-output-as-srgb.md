# LUT の出力は sRGB のコード値として扱い、P3 へは広げない

公式 LUT の出力は BT.709 ガンマのコード値だが、変換せずに sRGB として表示し、HEIC にも sRGB のタグを付けて保存する（#13）。比べる相手である富士のカメラの JPEG が sRGB なので、ΔE の復号と HEIC のタグを sRGB にそろえると、ΔE が見ているものと iPhone で見える画像が一致する。

もう 1 つの案は、こちらの出力だけを BT.709 / BT.1886 の EOTF で復号し、HEIC の BT.709 のタグに合わせることだった。この場合、ΔE の復号がカメラの JPEG（sRGB）とこちらの出力で別々になる。

LUT の出力を Display P3 へ広げる変換もしない。
