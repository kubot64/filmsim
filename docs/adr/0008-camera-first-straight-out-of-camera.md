# カメラを中心にし、撮影時にレシピで色を決めて撮って出しで使う

アプリは、撮影時にレシピで色を決め、保存された HEIC をそのまま使う人に向ける。撮ったあとに RAW をあれこれ現像したい人向けにはしない（2026-09-28 合意、#54〜#60）。

そのため、画面はカメラを全画面にし、レシピは撮影画面の帯で選ぶ。写真ライブラリには最終的に HEIC だけを保存する。DNG の保存と現像画面は、Settings の「開発用」にしまい、配布版では DNG の保存を初期値オフにする。色の検証が続く間は自分で DNG を撮るので、機能は残す（#59）。

それまでの画面は、カメラと現像をタブで切り替え、撮影と現像を同じ重さで扱っていた。

## Consequences

- 撮るたびに、写真の ID と使ったレシピを中身ごと記録する（#54）。あとでレシピを直したり消したりしても、撮ったときのものがわかる
- 確認画面では「現像し直す」を開発用のときだけ出す（#57）
